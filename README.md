julicq@github:~$ cat ./agentic-philosophy.md

# How I build with agents

  1. Agents > chatbots. A model that can read, plan, call tools and
     verify its own work beats a prettier prompt every time.
  2. Tools are the product. The agent is only as useful as the tools
     you give it — design them like APIs, not afterthoughts.
  3. Context is engineering. Caching, memory, retrieval and pruning
     are first-class concerns, not optimizations for "later".
  4. Loops, not one-shots. Real work happens in iterate→observe→correct
     cycles. Plan for self-recovery, not just happy paths.
  5. Evals or it didn't ship. If you can't measure agent quality,
     you're shipping vibes.
  6. Humans in the loop where it matters. Autonomy is a slider, not
     a switch — turn it up where the cost of a wrong action is low.
